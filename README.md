## 📌 Visão Geral do Projeto

Apresentação executiva interativa desenvolvida para a **Taranis Black Ergonomia Corporativa S/A** (faturamento consolidado de R$ 48 milhões/ano, 280 colaboradores).

O projeto estrutura a metodologia de **Vendas Consultivas B2B potencializadas por Inteligência Artificial**, superando o modelo transacional de "empurrar catálogo" através de:

1. **Diagnóstico Matemático de TCO** (Custo Total de Propriedade de R$ 1,98/dia útil frente a mobiliário genérico de varejo).
2. **Desbloqueio de R$ 4,69 milhões** em pipeline represado em 20 contas estratégicas através de régua condicional determinística.
3. **Governança Estrita com Travas Human-in-the-Loop (HITL)** para controle de margem, prazos fabris e especificações técnicas.
4. **Mini-App no Google Opal** e **Copiloto Especialista no Gemini Gem**, auditados com bateria Red-Team (100% de aprovação e salto de rubrica para 10/10).

## 🚀 Como Visualizar a Apresentação

### 1. Visualização Local (No seu computador)

Basta clonar o repositório e abrir o arquivo `index.html` em qualquer navegador web moderno:

```bash
# Clonar o repositório
git clone https://github.com/SEU-USUARIO/taranis-black-slides.git

# Acessar a pasta
cd taranis-black-slides

# Abrir no navegador (Windows)
start index.html
```

### 2. Visualização Online (GitHub Pages)

Este projeto é 100% compatível com o **GitHub Pages**:

1. No repositório no GitHub, acesse **Settings** > **Pages**.
2. Em **Build and deployment** > **Branch**, selecione `main` e a pasta `/ (root)`.
3. Clique em **Save**. Em instantes, o deck estará acessível em `https://SEU-USUARIO.github.io/taranis-black-slides/`.

## 💻 Funcionalidades Interativas do Deck

- **Navegação Inteligente**:
  - Setas do teclado (`←` e `→`), tecla `Espaço`, `Home` e `End`.
  - Botões dedicados na barra de controle inferior fixa.
  - **Menu Seletor de Capítulos (Dropdown)** para salto direto a qualquer um dos 22 capítulos.
- **Lightbox com Zoom em Alta Definição**:
  - Clique em qualquer print de evidência para visualizá-lo ampliado em tela cheia com alta legibilidade.
  - Feche clicando no `✕`, no fundo escuro ou pressionando a tecla `ESC`.
- **Engine de Impressão A4 Paisagem**:
  - Clique em `🖨️ PDF` ou use `Ctrl + P` para exportar todos os 22 slides perfeitamente paginados em formato A4 Paisagem, sem cortes nem páginas em branco.
- **Modo Contínuo**:
  - Botão `👁️ Contínuo` para alternar entre visão de slides sequenciais ou rolagem contínua de todo o documento.
